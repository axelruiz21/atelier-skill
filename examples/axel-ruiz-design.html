Studio

Axel Ruiz Design is a one-person studio in Austin, Texas, making typography that is grown, not set.

Each piece begins as a system — a seed, an algorithm, a handful of constraints — and ends as an edition: exact, reproducible, and built from nothing but type. The letterform supplies the terrain; the algorithm walks it.

The instruments are the ones named on the placards. Nothing on this page is an image: every work below is drawn live, in this file, from its seed.

Method

01
Seeded, Always
Composition never touches Math.random(). All chance flows from one integer through a seeded generator — the same seed yields the same frame, exactly. Exploring the work is navigation, not gambling.
02
Real Algorithms
Bridson's Poisson-disk sampling, Bowyer–Watson Delaunay triangulation, seeded Fisher–Yates, Box–Muller Gaussians — implemented inline, named on the placard. The craft should read in the code as clearly as on the wall.
03
One File
Every work ships as a single HTML file — no build, no server, no dependencies that rot. It opens from the filesystem today and will still open in twenty years. This page is built the same way.
